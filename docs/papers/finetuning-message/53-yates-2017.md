# Paper 53 — Depression and Self-Harm Risk Assessment in Online Forums (Yates et al. 2017)

> Family D (mental-health / suicide-risk SOTA) · foundational user-level baseline + RSDD dataset paper. Analysis depth: full PDF read (D17-1322, all 9 pages + Tables 1–5). Compiled 2026-06-25.

## Bibliographic info
- **Authors / Year / Venue:** Andrew Yates, Arman Cohan, Nazli Goharian. EMNLP 2017 (Copenhagen). ACL Anthology **D17-1322**, pp. 2968–2978. DOI **10.18653/v1/D17-1322**. (First two authors contributed equally; Yates @ MPI-INF Saarbrücken, Cohan/Goharian @ Georgetown IR Lab.)
- **Link:** [aclanthology.org/D17-1322](https://aclanthology.org/D17-1322/) · open (PDF VERIFIED, read end-to-end 2026-06-25).
- **RSDD dataset note:** introduces the **Reddit Self-reported Depression Diagnosis (RSDD)** corpus — **9,210 diagnosed users + 107,274 matched control users** (avg 969 posts/user, mean post length 148 tokens). Diagnosed users found via high-precision self-report patterns ("I was diagnosed with depression"), 3-annotator confirmation, ≥2 positive votes; mental-health subreddit/keyword posts stripped from diagnosed users to prevent leakage; controls matched 12:1 by subreddit-interest Hellinger distance. **Released under a Data Usage Agreement** (research-only, no deanonymization) at `ir.cs.georgetown.edu/data/reddit_depression`. Self-harm half uses the **ReachOut** youth-forum Triage data (65,024 posts, 1,227 annotated) from CLPsych 2016 — *not* RSDD.
- **R2 pillar:** related-work framing (user-level risk-assessment precedent) + a pre-transformer baseline row for the IEEE baselines table; secondary: ordinal-loss design lesson.

## Summary
A single **shared CNN architecture** ("identify features per post → merge post vectors → dense layers → output") instantiated for two tasks: (1) **user-level depression detection** on RSDD — a CNN with average-pooling aggregates a user's whole post history into one user vector classified binary depressed/control; and (2) **post-level self-harm risk** on ReachOut — the target post + its thread context are each CNN-encoded, concatenated, and classified on the **4-level ordinal scale green/amber/red/crisis**. Posts are encoded as skip-thought sentence vectors (to cope with ReachOut's small size), not transformer embeddings. The depression CNN beats BoW/feature-rich MNB/SVM baselines (User-CNN F1 **0.51**, recall **0.45** vs best baseline F1 0.44). For self-harm the team tests four losses — Categorical-CE, MSE, metric-learning, and a novel **Class Metric (Ordinal)** whose margin scales with class distance `α|p−n|` — finding CE best on test (non-green F1 **0.50**, all-class F1 **0.61**) but **Class Metric (Ordinal)** the most *robust* across test vs 10-fold CV (test all-F1 0.59 / CV 0.88, vs CE's 0.61 / 0.63), i.e. ordinal-aware modeling generalizes more stably.

## Best point — Framing / citation (with an embedded ordinal-loss design lesson)
The canonical **user-level mental-health risk-assessment precedent**: it established the "encode each post → aggregate to a user representation → classify the user" template that R2's seq-transformer + attention-pool reimplements with a modern backbone — *and* it already settled, on a 4-level crisis scale, that an **ordinal-margin loss is the more robust choice** (Class Metric Ordinal generalized test↔CV far better than flat CE), which is exactly R2's CORAL-vs-flat-CE thesis, predating it by 8 years.
- **How to apply to Pebble:** Cite Yates 2017 in R2 Related Work as the founding post→user aggregation baseline and as *prior evidence that ordinal-aware loss beats flat CE on graded suicide-risk* — turning R2's CORAL choice from "a trick we tried" into "a confirmed line going back to EMNLP'17."

## Caveats
- **Different task/ontology:** RSDD = binary depression; ReachOut self-harm = green/amber/red/crisis triage. **Neither is the C-SSRS 4-level ordinal scale** R2 targets — Yates is framing + loss-precedent + baseline-architecture, not a comparable benchmark.
- **Pre-transformer:** CNN over skip-thought/learned-term vectors; no contextual encoder. Its absolute numbers (depression F1 0.51; self-harm all-F1 0.61) are not comparable to NeoBERT/RoBERTa-era results and should be presented as a *floor*, not a target.
- **Dataset gated:** RSDD is **DUA-restricted** (research-only, no deanonymization); ReachOut Triage is CLPsych-2016 gated. Do not assume either is freely downloadable — both require agreements; not needed for R2 since the experiment runs on R2's own split.
- **Ordinal result not decisive in their hands:** Class Metric (Ordinal) was *most robust* but **not statistically better than CE on test** — cite it as "robustness evidence for ordinal margins," not "ordinal wins." R2's CORAL gold-holdout gain (QWK 0.241→0.378) remains R2's own evidence.
