## Summary
A 15K user-level corpus from r/SuicideWatch (14,613 posts / 1,265 users, from a 139K-post pool, 2020–2021), labelled on a 4-class C-SSRS-derived scale (Indicator / Ideation / Behavior / Attempt) with κ=0.72, preserving posting-time sequences. RoBERTa/DeBERTa baselines reach ≈0.77 macro-F1.

### What the paper actually does

- **Corpus construction.** Source pool is **not freshly crawled** — it is reused from ref [3]
  (Li et al., *HKIE Transactions* 2022, "Suicide risk level prediction and suicide trigger detection"):
  **139,455 posts from 76,186 users** on **r/SuicideWatch, 01/2020–12/2021**, via the official Reddit API.
  Li et al. labelled only 500 users / 3,998 posts; RSD-15K **re-selects and newly annotates 1,265 users /
  14,613 posts** from the same unannotated pool (§II-A1). ✔ (internal, consistent w/ stub).
- **Is it 15K?** The name is round-number marketing. The **annotated, valid corpus is 14,613 posts**
  (1,265 users) — Table I sums to 14,613 (809+2,056+7,133+4,615). "15K"/"15,000" is used loosely in the
  abstract and Table IV header. ✔ (Table I; abstract). Note Table II's own row says "14,613 Posts / 1,265
  Users" for "Ours" — but the same Table II lists Li et al. [3] as "15,755 Posts / 500 Users", an apparent
  typo vs the 3,998 figure given in §II-A1 (flagged ≈, internal inconsistency).
- **Label scheme — 4-class, C-SSRS-derived, post-level then aggregated to user-level (§II-B1):**
  - **Attempt** — post mentions a *previous* suicide attempt (a self-inflicted act intended to cause death
    that did not succeed), regardless of current ideation.
  - **Behavior** — preparatory acts: buying tools, writing a note, preparing for death; **self-harm is
    folded into Behavior** even when not intended to end in death.
  - **Ideation** — suicidal thoughts/desires without concrete action (passive + active; incl. unrealistic/
    hypothetical methods).
  - **Indicator** — **no suicide risk**: third-party suicide references, denial of intent, or concern about
    *someone else's* risk. (This is the negative/"no-risk" class — important: it is NOT a low-grade-risk tier.)
  - Severity order: **Attempt > Behavior > Ideation > Indicator**, mirroring CSSRS-Reddit (Gaur et al. [6]).
- **Class distribution (Table I, n=14,613):** Attempt **809 (5.54%)**, Behavior **2,056 (14.07%)**,
  Ideation **7,133 (48.81%)**, Indicator **4,615 (31.58%)**. ✔ (Table I). Steeply imbalanced toward
  Ideation; Attempt is the rare critical class.
- **Temporal ordering.** The headline novelty: posts keep timestamps + posting order; data is partitioned
  chronologically for risk-evolution tracking (§II-A2). The user-level task uses **the risk level of the
  user's *latest* post as the user's label**, over a sliding **time window of 5 posts** ("stable version
  has 5 window elements", §III). ✔ (§III).
- **Annotation protocol (§II-B2, §II-C1) — the genuinely strong part:**
  - **3 trained annotators + 3 supervisors**, all psychology-literate and fluent English.
  - **Pre-task gate:** 100 expert-labelled samples; an annotator must hit **≥95% accuracy** (re-train + re-
    annotate until reached) before formal labelling.
  - **Uncertainty-reporting policy:** ambiguous cases are *left unlabelled* and escalated to daily joint
    decision (explicitly to dodge confidence/confirmation bias) rather than guessed.
  - **Daily quota** 500 items/annotator; **daily 10% expert audit**, pass bar **≥85%** (all audits passed).
  - **Agreement:** **Fleiss' κ = 0.7206** on the **30% (4,384 samples) jointly labelled** subset; remaining
    **70% (10,229)** labelled independently. 3-person majority vote; disagreements re-reviewed. ✔ (§II-C1).
- **Benchmark (Table III, user-level 4-class, 80/10/10 *user-disjoint* split):**
  | Model | Acc % | MacF1 % | IN-F1 | ID-F1 | BR-F1 | AT-F1 |
  |---|---|---|---|---|---|---|
  | XGBoost (TF-IDF+time+seq feats) | 42.5 | 25.3 | 58.2 | 37.6 | 39.0 | 31.2 |
  | BiLSTM (+time encoding) | 48.6 | 36.7 | 61.5 | 41.2 | 41.1 | 33.2 |
  | HiGRU (hierarchical) | 52.2 | 30.3 | 64.4 | 45.8 | 44.0 | 39.2 |
  | RoBERTa (+temporal attn) | 71.0 | 65.0 | 72.0 | 73.7 | 72.0 | 71.0 |
  | **DeBERTa (+temporal attn)** | **76.0** | **77.0** | 76.0 | 78.9 | 76.0 | 77.0 |
  ✔ (Table III). All five baselines bolt a **custom temporal-attention / time-encoding module** onto the
  text model — they are *not* vanilla fine-tunes.
- **Scale ablation (Table IV).** DeBERTa-**Large (1.5B)** fully optimised on the **500-user** Li et al. set:
  Acc **74%**, MacF1 **0.74**. DeBERTa-**Base (86M)**, *no* tuning/balancing, on the **15K** set:
  Acc **76%**, MacF1 **0.70** — a smaller model on more data beats a 17× larger optimised model on accuracy
  (MacF1 slightly lower). ✔ (Table IV). Note Table IV's per-class F1 for the 15K-Base run (IN .79 / ID .80 /
  BR .60 / AT .59) **disagrees** with Table III's DeBERTa row (IN .76 / ID .789 / BR .76 / AT .77) — Table IV
  is the un-tuned Base variant, Table III is presumably the tuned/Large config; the paper never reconciles
  them, so the "76% acc / 77% MacF1" headline is the **best-config** number (≈, internal ambiguity).
- **Ethics/privacy (§IV):** usernames + post IDs + metadata stripped; claims no re-identification; public
  voluntarily-shared content only. **No IRB/REB number, no consent process, no formal license** stated.

### Parts directly useful for Pebble

1. **The 4-class C-SSRS scheme with explicit per-class definitions** — Attempt/Behavior/Ideation/Indicator,
   where **Indicator = no-risk** and **self-harm collapses into Behavior** (§II-B1). **[D-C]** This is the
   exact ontology Pebble's deferred C-SSRS severity head targets, and the definitions are reusable verbatim
   for a labelling guide / silver-label prompt.
2. **Severity-ordered bars on the same scheme:** DeBERTa **76% acc / 77% macro-F1 / per-class F1 ~.76–.79**;
   RoBERTa **71% / 65%** (Table III). **[D-C]** These are external sanity bars on the *4-class C-SSRS* task —
   directly comparable in scheme to the D-C target bars (52% acc / 0.75 wF1 / 47.8% macro-recall from
   CSSRS-Reddit) but on a **larger, higher-κ** corpus, so they are an *upper* reference, not a floor.
3. **The class-imbalance profile** — Attempt 5.5% / Behavior 14% / Ideation 49% / Indicator 32% (Table I).
   **[D-C]** A concrete prior for what an ordinal/distance-aware loss must cope with: the critical class
   (Attempt) is ~1/9 the size of the majority (Ideation) — argues for distance-aware/ordinal CE over flat CE
   so an Attempt→Indicator error is penalised more than Attempt→Behavior.
4. **The annotation QC protocol** — 95% pre-task gate, uncertainty-escalation, daily 10% audit, **κ=0.7206**
   (§II-B2/§II-C1). **[D-H]** A reusable *template* for Pebble's human-consensus validation slice (the FAIIR
   protocol's missing "how do you keep silver/expert labels consistent" piece), even though the *data* is
   unobtainable.
5. **Temporal / user-level framing** — latest-post-as-label over a 5-post window with user-disjoint splits
   (§III). **[D-H]** Confirms the "risk evolution over a session" signal Pebble cares about exists and is
   learnable; informs how a multi-turn severity signal could be aggregated, even though Pebble scores
   turn-level not user-level.
6. **Scale-beats-tuning evidence** (Table IV). **[D-D / D-C]** DeBERTa-Base-on-15K > DeBERTa-Large-on-500
   supports prioritising a *larger silver corpus* over an exotic backbone/loss for the severity head.

### How each part helps Pebble succeed

- **D-C (severity scheme + loss).** Adopt this paper's 4 class definitions as the canonical C-SSRS mapping in
  Pebble's severity head spec — crucially noting **two design forks** Pebble must decide: (a) **Indicator =
  no-risk** here, so a 4-class softmax is really 1 negative + 3 graded-risk tiers; map to Pebble's planned
  binary safety head as {Attempt,Behavior,Ideation→positive; Indicator→negative}, and to the ordinal severity
  head as a 4-level scale. (b) **Self-harm ∈ Behavior** here, whereas FAIIR (paper 01) treats *Self Harm* and
  *Suicide* as **separate** tags — Pebble must pick one convention and document it. Use the per-class F1
  (~.76–.79) as the **target ceiling** for a clean-label model and the imbalance profile to justify a
  distance-aware / ordinal loss over flat CE.
- **D-C (bars).** Log DeBERTa 76%/77% and RoBERTa 71%/65% as *external* reference points beside the CSSRS-Reddit
  D-C bars — but label them "different corpus, higher κ, user-level" so they are not mistaken for the
  turn-level target.
- **D-D (regression transfer / scale).** Table IV is a citation that **corpus size dominates model size** for
  this task — supports Pebble spending effort on a larger silver severity corpus rather than a bigger encoder.
- **D-H (datasets/substitutes).** Record RSD-15K as **aspirational-only**: re-confirmed 404, no license, no
  contact channel. Keep the stub's substitutes — **UMD Reddit Suicidality** (gated DUA/IRB, Resnik) and
  **CSSRS-Reddit / Gaur et al.** (the [6] this paper itself benchmarks against, post-level, obtainable) —
  as the real D-C training anchors. The κ=0.72 QC protocol is the *transferable* artifact, not the data.

### Child mental-health lens

- **Transfer risk — register: HIGH mismatch.** 100% adult/general r/SuicideWatch Reddit, explicit clinical
  self-disclosure ("I bought pills", "I wrote a note"). Pebble's child users express risk *obliquely,
  relationally, often coded* (cf. FAIIR's *home/school/friend* suicide keywords). The 76%/77% bars are
  almost certainly **optimistic** for child-register turn-level text; treat as an upper bound only.
- **Transfer risk — granularity: HIGH mismatch.** RSD-15K labels are **user-level (latest post over a 5-post
  window)**; Pebble scores **a single turn mid-conversation**. The temporal-attention modules that drive these
  baselines' gains are unavailable at turn-1, so the user-level F1 will not reproduce turn-level.
- **Transfer risk — Indicator semantics.** "Indicator = concern about *another* person / denial of intent =
  no-risk." For a child companion app this is a dangerous fold: a child saying "my friend wants to die" is
  third-party here (no-risk) but is *exactly* a case Pebble's safety pathway should still surface (mandated-
  reporting analogue). Pebble must **not** inherit the Indicator=no-risk mapping for the safety head; route
  third-party disclosures to escalation regardless of the self-severity label.
- **Ethics gap to avoid copying.** The paper's privacy treatment is thin (anonymise + "public data" claim, no
  IRB, no license). Pebble — child-facing, live decisions — cannot rely on a "public Reddit ⇒ fair game"
  argument; needs genuine ethics review + age-appropriate consent. The reusable *good* practice is the QC
  protocol (95% gate / uncertainty escalation / κ reporting), not the data-governance posture.

### Limitations & open questions for Pebble

- **Contradiction vs the stub's own headline & vs FAIIR (01):** the stub summarises "RoBERTa/DeBERTa baselines
  reach ≈0.77 macro-F1" — true for DeBERTa (77%) but **RoBERTa is only 65% macro-F1** (Table III); the ≈0.77
  is a *single-model* DeBERTa result, not a general baseline level. Also, unlike **FAIIR** (real youth-SMS,
  Suicide AUROC 0.94 on *child-register* text), RSD-15K's numbers are adult-Reddit user-level — so FAIIR, not
  RSD-15K, is the better existence-proof that child-register suicide signal is recoverable. RSD-15K's value to
  Pebble is the **label ontology + QC protocol**, not its metrics or its (unavailable) data.
- **Internal-consistency gaps (all flagged ≈ above):** Table II's "15,755 posts / 500 users" for Li et al. [3]
  contradicts §II-A1's "3,998 posts / 500 users"; Table III vs Table IV per-class F1 disagree (tuned-Large vs
  un-tuned-Base never reconciled); "15K"/"15,000" vs the actual 14,613. None are fatal but all weaken citing
  any single number as authoritative — prefer the *scheme* over the *scores*.
- **No ordinal/distance-aware loss is actually used** — despite a graded 4-class scheme, all baselines use
  plain classification heads. So this paper **motivates** D-C's ordinal-loss question (via its imbalance) but
  provides **no evidence on it** — that experiment is still Pebble's to run.
- **Data is a dead end (D-H):** 404 repo, zero public org repos, no DUA, unknown license — re-confirmed

- **Calibration:** none reported (no ECE / reliability) — same gap as every other paper in the set; Pebble's
  Decision Engine still needs calibrated probabilities the literature won't supply.
