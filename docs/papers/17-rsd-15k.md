## Summary
A 15K user-level corpus from r/SuicideWatch (14,613 posts / 1,265 users, from a 139K-post pool, 2020–2021), labelled on a 4-class C-SSRS-derived scale (Indicator / Ideation / Behavior / Attempt) with κ=0.72, preserving posting-time sequences. RoBERTa/DeBERTa baselines reach ≈0.77 macro-F1.

## Best point — Dataset to reuse
Same C-SSRS ontology Pebble already targets, but larger and temporally ordered.
- **How to apply to Pebble:** If obtainable, map its 4 classes onto Pebble's binary safety head (Attempt/Behavior/Ideation → positive, Indicator → negative) as extra supervision + a recall-stress test for the ≥0.95 floor; use its DeBERTa macro-F1 ≈0.77 as an external sanity benchmark.
