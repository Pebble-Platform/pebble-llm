1. Tổng quan

File Python tự chứa train một mô hình phân loại nguy cơ tự tử từ chuỗi bài post Reddit của một người dùng thành 4 mức ordinal (có thứ tự). Chạy được cả trên Kaggle GPU lẫn local CPU. Kiến trúc cốt lõi: dual-head — một đầu CORAL (ordinal) + một đầu classification — gộp lại khi dự đoán. 
luồng dữ liệuIndicator (0) → Ideation (1) → Behavior (2) → Attempt (3)

5 posts của 1 user
   │
   ▼
[RoBERTa encoder]  ──► 5 CLS vectors (B, S, h)
   + temporal embedding (Δt)
   ▼
[3-layer Transformer over sequence]
   ▼
[attention pooling, learnable query] ──► 1 vector u (B, h)
   + [stat-feature MLP fusion]
   ▼
   ├─► CORAL head  (ordinal)
   └─► CLS head    (classification)
        ▼
   p_final = 0.5·CORAL + 0.5·CLS  ──► argmax ──► nhãn 0-3

Hai nhánh đỏ là dual-head; phần "5 posts → 1 vector user" là tính hierarchical (post-level rồi user-level).

dòng 125–134def _parse_posts(cell: str) -> list[str]:
    """Cột 'Post' là python-list-as-string. 28/500 fail literal_eval (escapes)
    → fallback dùng raw cell làm 1 post."""
    try:
        v = ast.literal_eval(cell)
        if isinstance(v, list) and v:
            return [str(x) for x in v if str(x).strip()]
    except Exception:
        pass
    return [cell.strip("[]")]

Cột Post trong CSV là list Python lưu dạng chuỗi → parse bằng ast.literal_eval; 28/500 dòng lỗi escape thì coi cả ô là 1 post.

dòng 313–327 (freeze + encode)def _freeze(self, k):
    for name, p in self.encoder.named_parameters():
        if name.startswith("embeddings"): p.requires_grad = False
        elif ".layer." in name:
            li = int(name.split(".layer.")[1].split(".")[0])
            if li < k: p.requires_grad = False     # khóa k layer đầu

def encode_posts(self, input_ids, attention_mask):
    B, S, L = input_ids.shape
    out = self.encoder(input_ids=input_ids.view(B*S, L), ...)   # 1 lần cho cả 5 post
    return out.last_hidden_state[:, 0].view(B, S, self.h)    # lấy CLS
dòng 329–343 (forward)def forward(self, input_ids, attention_mask, valid, dt, feats):
    e = self.encode_posts(input_ids, attention_mask)        # (B,S,h)
    e = e + self.time_drop(F.relu(self.time_ln(self.time_fc(dt.unsqueeze(-1)))))
    pad_mask = ~valid                                       # True = pad (bỏ qua)
    s = self.seq_encoder(e, src_key_padding_mask=pad_mask)   # transformer chuỗi
    q = self.query.expand(e.size(0), -1, -1)
    u, _ = self.pool(q, s, s, key_padding_mask=pad_mask)      # gom → 1 vector user
    u = self.pool_drop(u.squeeze(1))
    if self.cfg.use_features:
        u = self.fuse(torch.cat([u, self.feat_mlp(feats)], dim=-1))  # fuse stat-feature
    coral_logits = self.coral_fc(u) + self.coral_bias       # (B, 3)
    cls_logits   = self.cls_head(u)                       # (B, 4)
    return coral_logits, cls_logits

Hierarchical: encode_posts reshape (B,S,L)→(B·S,L) để chạy encoder một lần cho cả 5 post (hiệu quả), lấy CLS. Sau đó sequence transformer + attention pooling (1 learnable query) gom 5 vector thành 1 vector đại diện user.

Dual-head: coral_fc dùng 1 weight chung + coral_bias 3 ngưỡng có thứ tự → đây là điểm mấu chốt CORAL, đảm bảo dự đoán đơn điệu. cls_head là classification thường.

_freeze(6) khóa embeddings + 6 layer đầu của RoBERTa (~50% như paper) để fine-tune nhẹ.

6. Losses dòng 347–372

dòng 347–360def coral_loss(coral_logits, y, n_classes):
    levels = torch.arange(n_classes - 1, ...).unsqueeze(0)
    t = (y.unsqueeze(1) > levels).float()        # mục tiêu nhị phân t_k = 1[y > k]
    return F.binary_cross_entropy_with_logits(coral_logits, t)

def focal_loss(cls_logits, y, alpha, gamma):
    logp = F.log_softmax(cls_logits, dim=-1); p = logp.exp()
    p_y = p.gather(1, y.unsqueeze(1)).squeeze(1)
    return (-alpha[y] * (1 - p_y) ** gamma * logp_y).mean()  # tập trung sample khó
dòng 363–372def coral_to_probs(coral_logits, n_classes):
    """cumulative P(y>k) → xác suất từng lớp."""
    pgt = torch.sigmoid(coral_logits)               # P(y>k)
    probs[:, 0]  = 1 - pgt[:, 0]                     # P(y=0)
    probs[:, k]  = pgt[:, k-1] - pgt[:, k]            # P(y=k)
    probs[:, -1] = pgt[:, -1]                        # P(y=last)
    return probs.clamp_min(1e-6)
dòng 441–443 (tổng loss, paper eq.4)loss = (cfg.w_coral * coral_loss(coral, y, n_classes)        # 0.5
        + cfg.w_ce   * F.cross_entropy(cls, y, label_smoothing=...)  # 0.3
        + cfg.w_focal * focal_loss(cls, y, alpha, gamma))    # 0.2

CORAL: biến nhãn thành 3 bài toán nhị phân y>0?, y>1?, y>2? (vd y=2 → [1,1,0]). Vì chung 1 weight + bias có thứ tự → dự đoán không bao giờ mâu thuẫn. coral_to_probs chuyển P tích lũy thành P từng lớp bằng hiệu các tầng.

Focal (alpha theo tần số + gamma=2) chống mất cân bằng. Tổng loss = 0.5·CORAL + 0.3·CE + 0.2·Focal.

Tại sao gold-holdout? Pool mở rộng được gán nhãn bởi LLM. Nếu đánh giá trên chính nhãn LLM thì circular (ảo tưởng cao). Giải pháp: train trên pool nhãn-LLM (5-fold CV), nhưng luôn đo trên tập gold lâm sàng giữ riêng. Chỉ số GOLD mới là con số trung thực để báo cáo thesis.

9. Tóm tắt & cách chạy

3 điểm thiết kế quan trọng nhất

  1. Dual-head CORAL + CLS: ordinal regression (giữ thứ tự nguy cơ) + classification thường, average xác suất lúc predict.
  2. Hierarchical: post-level encoder (RoBERTa) → user-level sequence transformer + attention pooling.
  3. Gold-holdout: train trên nhãn-LLM nhưng đo trên nhãn lâm sàng giữ riêng → tránh đánh giá circular.
