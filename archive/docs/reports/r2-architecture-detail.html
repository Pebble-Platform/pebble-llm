③ Dual-head & cách gộp (blend) — ordinal + nominal bù nhau

CORAL → xác suất lớp (luỹ tích P(y>k) → per-class):
P(y>k) = σ(coral_logits) # k=0..2 probs[0] = 1 − P(y>0) probs[k] = P(y>k−1) − P(y>k) probs[3] = P(y>2) # giữ thứ bậc: ngưỡng coral_bias có thứ tự
Blend lúc eval (chỉ gộp head thực sự được train):
coral_p = coral_to_probs(coral_logits) cls_p = softmax(cls_logits) p_final = 0.5·coral_p + 0.5·cls_p # nếu cả 2 head bật ŷ = argmax(p_final) # ablation: chỉ 1 head → dùng riêng head đó
CORAL cho thứ bậc (nhầm Indicator↔Attempt bị phạt nặng hơn nhầm kề), CLS cho sắc lớp. Blend 50/50 lấy ưu điểm cả hai.

④ Loss tri-objective — paper eq.4

L = 0.5·LCORAL + 0.3·LCE(label_smoothing=0.1) + 0.2·LFocal(γ=2) # trọng số env-gated: R2_W_CORAL/CE/FOCAL LCORAL = BCEWithLogits( coral_logits , t ) tk = 1[y > k] # mục tiêu nhị phân luỹ tích LFocal = mean( −αy·(1−py)γ·log py ) α = N / (C·count) # α nghịch tần suất lớp
Đây là loss của bản đã ship (CORAL+CE+Focal). Bản mới nhất thay CORAL→CORN (weight riêng mỗi ngưỡng) và Focal→GCE (giảm trọng số mẫu tin-cậy-thấp) — xem mục ⑧.

⑧ 3 cải tiến mới nhất — delta kiến trúc/inference/data so với bản ship

1 · CORN + GCE — loss ordinal bền-nhiễu (xương sống)

Thay CORAL (1 weight chung → 1 nhãn hiếm nhiễu hỏng mọi ngưỡng) bằng CORN (weight riêng mỗi ngưỡng); thay Focal bằng GCE (giảm trọng số mẫu tin-cậy-thấp).
→ Behavior-F1 0.183 → 0.317 · gold 0.385 → 0.418 · vẫn giữ ordinal (QWK ~0.39). Đổi ở head + loss.

2 · Label-shift correction — sửa dịch-chuyển nhãn LLM→gold (inference, 0 train lại)

Đo π_gold/π_train Behavior = 3.0× (LLM under-label); Logit-Adjustment hậu kỳ cộng log w(y) vào logits.
→ Behavior-F1 0.357 → 0.41 (oracle 0.44), macro +0.005→+0.029. Chỉ đổi ở bước inference.

3 · Ordinal-aware Confident Learning — làm sạch nhãn theo thứ bậc (data)

Confident-joint trọng số |ỹ−ŷ|²: sạch 100% lỗi-xa (Behavior→Indicator) nhưng giữ 78% lỗi-kề (borderline). Cleanlab nominal flag bừa 45% lỗi-kề.
→ chẩn đoán 35.8% nhãn Behavior nghi sai; cleaning đúng lâm sàng. Đổi ở tiền xử lý data.
